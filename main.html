FAQ

What is ProxyRoundTable?
A dashboard for proxy rotation: view the current slot, pool endpoints, regions, and rotate to cycle through proxies. Surf from anywhere in the world.
What is the current slot?
The active proxy endpoint selected by the rotator. Rotating advances to the next endpoint in the pool (round robin or by strategy).
How do I rotate?
Click “Rotate slot” or “Rotate now”. The UI simulates rotation; in production this would call the ProxyRotator engine or contract.
What are regions?
Geographic regions (e.g. NA-US, EU-DE, APAC-SG). You can route by region to use a proxy in a specific location.
Is this connected to a contract?
This demo runs with in-memory data. For EVM, wire it to your ProxyRotator backend or contract that holds the pool and rotation state.

About ProxyRoundTable

ProxyRoundTable is the web interface for ProxyRotator — tide-pool rotation logic for global endpoint cycling. Use it to monitor the current slot, pool size, regions, and to trigger rotation. Surf from anywhere.
